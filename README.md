### Sprint_4 — UI-автотесты для сервиса «Самокат»

Этот проект содержит UI-автотесты для веб-приложения «Самокат».
Тесты написаны с использованием Java 11, JUnit 4, Selenium WebDriver и Maven.
Реализованы Page Object, параметризованные тесты, позитивный сценарий заказа самоката и проверка выпадающего списка с вопросами.

| Технология         | Версия   |
| ------------------ | -------- |
| Java               | 11       |
| Maven              | 3.9.0    |
| JUnit              | 4.13.2   |
| Selenium WebDriver | 3.141.59 |
| WebDriverManager   | 6.3.3    |

### Настройка перед запуском

Дополнительная установка драйверов не требуется — всё делает WebDriverManager.

Тесты запускаются в Google Chrome или Firefox (если реализован выбор браузера).

Запуск всех тестов в браузере Chrome: mvn clean test

Запуск всех тестов в браузере Firefox: mvn clean test -Dbrowser=firefox
